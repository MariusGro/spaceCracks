# spaceCracks
A simple space shooter pixel art game made with the godot engine.

### About this project
- This is supposed to be a small project to practice not only my game development skills but also how to properly use git / github for version control.
- Everything in this project is made by me, except for maybe some clanker code. However all assets are entirely handdrawn in aseprite.
- This game is not supposed to be very original or be that big in scope. This is more a preparation for possible bigger future projects... (you gotta start somewhere)
- Feel free to use everything in this project for your personal purposes.

### About this game
This game is a simple space shooter with a pixel-artstyle. My goal for this project is less originality and more about making a complete game with a high level of polish.
That for example includes nice looking menus and all the other suff that is not gameplay.

### About me
I am a guy with only one prior gamedev-experience in a scool project. I started coding in 2023 and my coding skills are just above ChatGPT at best.
I have no clue about art or music, but I will try it nevertheless. I want to have something where I can say that it was entirely made by me. For the future this project will also serve to see, what I can do, what I can learn and for what I should team up with oter people.
Feel free to give feedback and no need to hold back. 

### What tools I use
- This project is made with the godot engine
	- I use GDScript for coding (default)
- The assets in this game are made with aseprite (I am sorry that I did not pay for it and instead build it from github with a youtube guide)
	- I use the rosy-42 color palette
- Github-Desktop for version controll (I am scared about using the terminal)
